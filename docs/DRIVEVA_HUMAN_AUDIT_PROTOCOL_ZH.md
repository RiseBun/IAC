# DriveVA 生成运动盲法审计（v1）

## 目的

DriveVA 的 scene-disjoint 50-twin holdout 在当前 S1.3 下有足够 coverage（92.0%），
但正常顺序方向准确率只有 52.6%。这个结果可能来自三种不同原因：

1. DriveVA 没有按左右 action 产生稳定的可见变化；
2. 视频中有变化且方向正确，但 S1.3 的 `horizontal_flow_center` 没有读出来；
3. branch 身份、左右方向或图像 geometry adapter 存在系统性错配。

人工审计只用于区分这三种情况，不替代候选盲自动指标，也不把人工判断写入正式
CCFC-S/CFAC 分数。

## 两阶段盲法

### A 阶段：只看视频，不看 action

- 每个 twin 显示固定 history 和左右两段未来视频；随机交换屏幕上的 L/R 标签；
- 隐藏 action 数值、stratum、模型名称和 S1.3 输出；
- 对每个分支逐 interval 标注：`向左`、`向右`、`前进/无明显横向`、`不可判断`；
- 另标注：是否存在持续的可见运动、两支是否有差异、差异从哪个时刻开始；
- 10% twin 做重复呈现，检查同一标注者的稳定性。

### B 阶段：揭示 command，检查一致性

- 向标注者显示该 twin 的左右 action 方向，但不显示 S1.3 结果；
- 对每支回答“可见方向是否与对应 action 一致”；
- 单独保留 `看得到变化但方向不确定` 与 `看不到变化`，不能合并成错误。

每个 twin 至少 3 名标注者。报告 majority vote、Krippendorff’s alpha（或 Fleiss κ）、
重复样本一致率，并保留每个标注者的原始标签。

## 必须包含的控制

- 正常顺序：原始图像和 action 配对；
- 顺序反转：只交换图像的左右身份；
- 身份错配：图像保留、action 互换；
- 零差异：两支视频相同或差异低于预注册阈值。

控制样本与正式样本混排，标注者不能知道控制类型。若控制本身不能被人工稳定区分，
本轮审计无效。

## 判定矩阵

| 人工观察 | S1.3 | 解释 |
|---|---|---|
| 正确方向、持续差异 | 近随机 | 测量器/descriptor 失配；优先做 descriptor 和时序流审计 |
| 无稳定方向或无差异 | 近随机 | DriveVA 生成层未形成可用反事实响应；不是简单调阈值 |
| 系统性反向 | 反向或近随机 | branch/action 身份、坐标方向或 adapter 可能错位 |
| 正确方向、S1.3 也高 | 正常 | 自动测量得到人工支持，可扩大确认集 |

只有第一种情况才支持“DriveVA 有可见运动但 S1.3 不会读”的结论；第二种才支持
“DriveVA 本身没有稳定响应”。两者不能仅由 52.6% 自动命中率区分。

## 样本与报告

优先审计 50-twin holdout 的全部 twin（包括 4 个自动 unavailable），至少保证所有
stratum 和自动控制状态都有样本。正式报告同时给出：

- 自动 coverage、方向准确率及 CI；
- 人工可判断率、方向准确率及标注一致性；
- 人工标签与 S1.3 的 twin-level agreement；
- 正常、倒序、错配、零差异四类控制的结果；
- 任何 geometry adapter、视频解码或帧时间轴异常。

人工结果只能作为根因诊断和测量器验证证据。不得用人工标签挑选样本、调阈值后再
报告同一批的自动分数。
